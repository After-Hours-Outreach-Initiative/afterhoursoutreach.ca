Browse every email the application can send, including approval, access, event,
patrol series, and medic reminder variants. The previews use the same message
formatting as delivery, with fictional recipients and inactive example links.
Nothing is sent, and no database, application server, or credentials are needed.

Only the sign-in email currently includes HTML. All other messages are plain text;
the gallery preserves that distinction rather than inventing HTML designs.

orientation completion do not send emails, so they have no previews here.
