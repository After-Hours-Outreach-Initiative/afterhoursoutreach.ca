# Organizer tools

What organizers can do.

## Volunteers

A volunteer list at `/organizer/volunteers`:

- Filter by status: pending, approved, inactive.
- Filter by team and medical certification.
- Open a volunteer to see their full profile.
- Approve a pending volunteer, or mark a volunteer inactive.

Only approved volunteers can sign up for patrols.

## Patrols

Organizers get extra controls on `/patrols`: create, edit, close, and delete
patrols, and see the roster for each one. See
[patrol-scheduling.md](patrol-scheduling.md).

The roster shows each volunteer's name, phone, team, and certification, so the
patrol lead can see who is a medic.

## Access log

Every time an organizer opens a volunteer's full profile, the organizer, the
volunteer, and the time are saved. Organizers can see the log.

## Two factor

Organizer pages need a passkey or TOTP to be set up first. See
[accounts.md](accounts.md).
