# [afterhoursoutreach.ca](https://afterhoursoutreach.ca)

The After Hours Outreach Initiative website, built with Astro and hosted on
Cloudflare Workers.

```sh
pnpm install
pnpm dev       # application at http://localhost:4321
pnpm docs:dev  # documentation at http://127.0.0.1:4322
```

The documentation in [docs/](docs/src/content/docs/) covers development,
testing, deployment, and the product specification. Start with
[Local development](docs/src/content/docs/implementation/development.md).
Work is tracked in
[GitHub issues](https://github.com/After-Hours-Outreach-Initiative/afterhoursoutreach.ca/issues).
